Every loaded segment of the executable is rebuilt (`tools/layout_link.py`): the bytes **from source** are the claimed functions and data objects laid out at their addresses with relocations resolved; the rest is taken from the user's own executable at build time, and the whole must equal the base byte for byte, which the gate requires. `.bss` holds no file bytes, so its figure is ownership: how much of it a claimed object defines.

A function is **matched** when its compiled instructions equal the base executable's at its address, with only the fields the linker fills (RIP-relative displacements, call targets, GOT and PLT slots) masked (`tools/match_check.py`). The function list and sizes come from the executable's own unwind tables (`tools/survey_elf.py`, `config/functions.base.txt`); the `.text` row's total is the whole executable segment, including the bytes between functions.
