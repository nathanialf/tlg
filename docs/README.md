# docs/

An index of this directory: what each file is for.

| file | what it is |
| --- | --- |
| [`BUILDING.md`](BUILDING.md) | the full build: host packages, what `./build.sh`, `tools/setup.sh` and each step do, the hooks, the dashboard |
| [`LEGAL.md`](LEGAL.md) | what the repository may and may not contain, and which references were used. Read it before contributing |
| [`MATCH.md`](MATCH.md) | the matching workflow: pick a function, write its C++, diff, claim; what the comparison masks |
| [`TARGETS.md`](TARGETS.md) | the target, what its executable says about its own build, and the open question of the matching compiler |
| [`SURVEY.md`](SURVEY.md) | the executable's map: program headers, function counts, libraries, imports, the source paths it names. Generated by `tools/survey_elf.py --md` |
| [`base/`](base/) | the target's progress files: `PROGRESS.md`, the table of matched functions and bytes, and `progress.json`, its data. Generated by `tools/check_elf.py --progress` |
| `index.html` | the progress dashboard, which reads `base/progress.json`; `.github/scripts/build_pages_site.sh` publishes it with `base/progress.json` and `base/PROGRESS.md` to GitHub Pages, and nothing else from this directory |

`tools/README.md` describes every tool.

## Local files that are not part of the repository

A maintainer's checkout may also hold `NOTES.md` and `COOKBOOK.md` here:
notes on the compiler's behaviour and parked functions. They are gitignored,
nothing in the build reads them, and nothing in the repository depends on
them.
