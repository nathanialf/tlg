# Compiler flags per source prefix, for tools/compile_cpp.sh. The longest
# prefix that matches the source path wins; flags apply to every file under it
# (per directory, never per file or per function). A line may start with
# `cxx=<name>` to compile that prefix with tools/cc/llvm-<name>/bin/clang: a
# prebuilt release (tools/fetch_llvm.sh) or, for <version>-src, one built
# from source (tools/build_llvm.sh); otherwise the project default applies.
#
# The executable holds two compiler generations (docs/TARGETS.md, "Two
# compiler generations"; docs/DECISIONS.md D6):
#   src/libs/   code below 0x1a3e00: third-party and Sony libraries built
#               years earlier (Havok 2014.2 nightly of 2014-11-21 among them)
#               with an LLVM 3.3-generation compiler: movsxd rax,eax never
#               shrunk to cdqe (678 sites), constant stores not merged, no
#               post-RA scheduling. Upstream 3.3 knows no PS4 triple; the
#               FreeBSD 9 x86-64 target is the ABI the PS4's was derived from.
#               745 of its 3,391 functions load the stack canary, those that
#               take a local's address (D20: the strong level). The compiler
#               is upstream 3.3 built from source (cxx=3.3-src,
#               tools/build_llvm.sh 3.3), verified byte-identical to the
#               prebuilt release on the probe and on every TU, carrying five
#               backports: clang 3.5's -fstack-protector-strong frontend
#               (tools/patches/llvm-3.3-sspstrong-01-*.patch; 3.3's backend
#               already implements sspstrong), passed here; one nop after
#               the stack check's failure call (sspnop, D26); one store
#               merge per visit of a store (storemerge, D27); a function's
#               jump tables before its end label (jumptable, D28); bextr
#               from a shifted, masked value (bextr, D29). -g since round
#               43 (D30): the region was built with debug information, which
#               3.3's peephole counts as a use (a load whose value a named
#               local holds is not folded into its one real user).
#   src/game/   code from 0x1a3e00 up, the game and engine, built with the
#               SDK 3.5 compiler: cdqe, merged constant stores (3,065), ud2
#               after noreturn calls (503), int 0x41 debug traps, no
#               vzeroupper around 32k ymm uses. The nearest upstream
#               release is 3.7.1 (D81; rounds 268B to 276B: the same module
#               under the prebuilt 3.8.1 holds 4,893 of 5,497 game rows
#               where 3.7.1 holds 5,302 with the PS4 items alone). Built
#               from source (cxx=3.7.1-src, tools/build_llvm.sh 3.7.1) with
#               seventeen patches (tools/patches/llvm-3.7.1-*.patch, each with
#               its evidence and its sweep in its header). Four PS4 items:
#               one nop after the stack check's failure call (sspnop, D26);
#               a thread-local with local linkage kept general-dynamic
#               (tlsprot, D75); a weak-linkage structor emitted as its own
#               function (structor, D45); a trap after a noreturn call
#               (trap, upstream r264224). Six forward ports of later
#               upstream changes the base shows: the inliner credits the
#               call instruction it removes (inlinecall, r286814); the
#               compiler-made init and destroy functions get a definition's
#               attributes (initattrs, r249722, r249735, r251734); a
#               select's expensive operand is sunk into a branch (selsink,
#               r248439, r250743, r255660); a floating-point constant's
#               store becomes an integer store after the merge attempt
#               (fpstore, r248168, r248169, r248190); the loop-closed phis
#               are removed after the late LICM (lcssa, r271602); a field
#               of a struct declared with an alignment is aligned as the
#               struct is (fieldalign, one number of r246985). One
#               local rule of the two-stage module (D83), no upstream
#               state: the link stage's GVN does no scalar PRE (ltopre;
#               a second one, tlsbonus, was removed by D87: the stock
#               fold it forbade is what the base shows). One local
#               rule of the btver2 scheduling model, no upstream state: a
#               locked exchange-add is one micro-op (lxadd). One local
#               rule of the unit pipeline, no upstream state: at -O2
#               LoopUnswitch unswitches non-trivially on a branch whose
#               whole condition is loop-invariant, and on no switch,
#               select or part of an and/or (unswitch). One local
#               rule of memory dependence, no upstream state: an ordered
#               atomic read-modify-write does not modify a frame object
#               that nothing before it captured or was handed to write
#               (atomic). One local rule of JumpThreading, no upstream
#               state: a block that holds an atomic read-modify-write or
#               a compare-exchange is not duplicated (jumpthread). One
#               local rule of instruction selection, no upstream state: a
#               one-use float load converted to double is the memory form
#               of vcvtss2sd over a zero of the block (cvtzero, D95). One
#               local rule of the tail merge, no upstream state: an
#               atomic read-modify-write of 32 bits or less ends a common
#               tail and its block is not tail-duplicated (tailmerge,
#               D96). In the order they apply (the glob's): atomic,
#               cvtzero, fieldalign, fpstore, initattrs, inlinecall,
#               jumpthread, lcssa, ltopre, lxadd, selsink, sspnop,
#               structor, tailmerge, tlsprot, trap, unswitch.
#               5,980 of its 16,344 functions load a stack canary, those that
#               take a local's address or hold an array (tools/fingerprint.py
#               --range 0x1a3e00:, D20): the Orbis default
#               -fstack-protector-strong.
#
# Evidence for the common flags, from the matched functions:
#   -O2                             -O1 and -Os lose the vectorised and
#                                   scheduled forms the base has
#   -march=btver2                   the Jaguar: its instruction set is in use
#                                   (bextr 1,328, andn 108, lzcnt 69, movbe 14)
#   -mllvm -pre-RA-sched=list-ilp   removed from the game line on 2026-11-14,
#                                   after an audit of the whole game module
#                                   without it: every row that needed it is
#                                   written in ordinary C++ with its reads in
#                                   the base's order (22 rows; 0x75f2c0 by the
#                                   layout of its lock scope), and 316 drafts
#                                   are equal without it. The DAG scheduler is
#                                   upstream's default, the source-order one.
#   -mllvm -x86-use-vzeroupper=false
#                                   no vzeroupper before a call or a return
#                                   after ymm code: the base has none around
#                                   its 32k ymm uses; 3.3 and 3.7.1 insert it
#                                   for btver2 by default (both lines)
#   (no other -mllvm option on the game line)
#                                   the 4.0.0 line carried four, each
#                                   switching off something 3.7.1 does not
#                                   have: -no-x86-call-frame-opt (D55: 3.7.1's
#                                   pass pushes no argument on a 64-bit
#                                   target), -tail-dup-placement=false (D61:
#                                   r283934, first in 4.0), -disable-preheader-prot
#                                   (D80: r265397, first in 3.9),
#                                   -jump-table-density=40 (D72: 3.7.1's
#                                   density is 40)
#   -fPIC                           the executable is position independent
#                                   (ET_SCE_DYNEXEC, 29k relocations); an
#                                   Orbis driver default (Sony's 2013 LLVM dev
#                                   meeting slides, docs/TARGETS.md)
#   -fstack-protector-strong        an Orbis driver default (same slides); the
#                                   executable imports __stack_chk_fail and
#                                   __stack_chk_guard; 6,725 functions load
#                                   the canary, the address-taking ones (D20),
#                                   in both regions
#   -fno-exceptions -fno-rtti       Orbis driver defaults (same slides)
#   -fno-math-errno                 the upstream PS4 toolchain's default
#   -ffast-math (game, not src/game/sndx/)
#                                   the game's float code is reassociated and
#                                   takes no account of NaNs: a sum of products
#                                   is emitted highest rank first (0xf51a20 and
#                                   its copies, 0x762bd0, 0x7790f0, 0x108d770,
#                                   0x109ddf0: equal under the flag with 3.7.1,
#                                   3.9.1 and this compiler, under no narrower
#                                   flag); of the region's 25,734 float
#                                   compares 94 carry a parity branch and of
#                                   its 4,041 divisions 29 are by a constant,
#                                   every one of them inside 0xec18b0 to
#                                   0xf15220, the sndx sound runtime (a C
#                                   library by its assert strings' file names,
#                                   sndx_buss_fx.c among them, linked into the
#                                   game): src/game/sndx/ holds the units whose
#                                   functions lie there and is the game line
#                                   without the flag
#   -fno-honor-nans (libs)          the library region's float equality
#                                   tests carry no parity branch (121 sites
#                                   with none, 0 with one; the game region
#                                   3,047 and 91): D24. The narrowest flag
#                                   for that evidence; -ffinite-math-only
#                                   and -ffast-math pass the gate too and
#                                   wait for a function that needs them
#   -funsafe-math-optimizations     (libs) cc1's -menable-unsafe-fp-math
#                                   alone: 0x158e20 negates a factor across
#                                   a subtraction, which DAGCombiner does
#                                   only under it; every row equal under
#                                   the flag, no library division by a
#                                   constant (130 divisions; the game
#                                   region keeps 30): D40
#   (no -fwrapv)                    D3 took it from 0x12120's shape, which
#                                   is unmatched; 0x13d80 matches only
#                                   without it and every claimed row matches
#                                   either way (D24); the game line loses
#                                   it on the same absence of evidence
#   -fno-strict-aliasing            the base reloads a field after a store
#                                   through another type (0x12120, 0x79a5d0)
#   -fno-omit-frame-pointer         14,410 of 14,414 non-leaf functions keep
#   -momit-leaf-frame-pointer       rbp; 5,200 of 5,304 leaves omit it
#   -std=gnu++11                    the Orbis driver's default dialect (slides)
#   -fshort-wchar -D__ORBIS__       the PS4 target's wchar_t is unsigned short
#   -D__PS4__                       and these are its macros (clang 3.7+)
#   -fvisibility=protected (game)   the game is one module (D50, tools/game_module.py):
#                                   its own functions and objects are reached
#                                   PC-relative and called without the PLT,
#                                   the libraries' through the GOT; protected
#                                   is the visibility that gives both under
#                                   -fPIC (round 124A's witnesses)
#   -ffunction-sections (game)      a call between two functions of the one
#                                   module object keeps its relocation (the
#                                   assembler resolves a call inside one
#                                   section, and a protected callee has no PLT
#                                   entry to keep it: round 133A)
#   -nostdlibinc -nostdinc++        no host libc headers (src/include/ carries
#                                   our own, FINISHING rule 8); the compiler's
#                                   intrinsic headers (xmmintrin.h) stay. Not
#                                   -ffreestanding: it turns builtins off, and
#                                   the base lowers memcpy, memmove and memset
#                                   as builtins (D11: libs 64 calls, 0 tail
#                                   jumps; game 1,417 calls, 18 tail jumps)
#   src/sce/    the Sony SDK objects at the head of the game region,
#               [0x1a3a70, 0x1afa60): six input objects (one CIE each in
#               .eh_frame; the game is one CIE from 0x1afa60), their
#               functions only called from the game, never inlined there,
#               while one object inlines its own (0x1a7000 in 0x1a6f70):
#               built by the game compiler at the game line, each unit an
#               object of its own outside the game module (round 454B)
src/libs/ cxx=3.3-src -target x86_64-pc-freebsd9 -O2 -march=btver2 -mllvm -x86-use-vzeroupper=false -ffunction-sections -fPIC -fstack-protector-strong -fno-math-errno -fno-honor-nans -funsafe-math-optimizations -fno-strict-aliasing -fno-exceptions -fno-rtti -fno-omit-frame-pointer -momit-leaf-frame-pointer -nostdlibinc -nostdinc++ -std=gnu++11 -fshort-wchar -D__ORBIS__ -D__PS4__ -Isrc/include -g
